Fix: Gated Becomes Never

claude-skills + ~/.claude global · 2026-06-24 · Status: revised, passed adversarial gate (verdict was "rethink")

This is the work-ledger fix, grounded in a forensic trace of a real failure: three feed cards you asked for were never built across three sessions. The trace proved the handoffs worked. The items were not lost. They were starved by gating: each needed a design call, so each session parked them as "needs Sean's input" and asked instead of building. With nothing to force the issue, gated quietly became never.

1. TL;DR

Two moves, anchored on a pattern you have already proven. Prevent the gate (a strawman-by-default rule, promoted from one project's memory to global), and detect when prevention fails (a structural check on carried-forward items, wired into the skill that was actually in the failure chain). The detection half mirrors the exact hybrid (prose default plus a harness hook) you already shipped to kill "completion theater."

3. The anchor: you already solved this once

The strongest part of the revised plan is that it is not new. Your feedback-evidence-based-done memory documents that you hit this exact "discretionary prose does not fire" wall for completion theater, and you fixed it with a hybrid:

A prose orchestrator-prompt edit is discretionary firing, NOT enforcement. Only a harness hook fires by default. So ship-quality ships as: callable skill + standing prose default + a real SubagentStop hook (~/.claude/hooks/ship-quality-gate.sh) that injects the evidence checklist on every subagent return.

This plan applies the same shape to gated-never. Prose for the behavioral half (prevention), a harness tripwire for the structural half (detection). Proven pattern, new target.

4. The fix

Lever 1 — Prevention promote, do not merge

Move: promote only feedback-gated-items-become-never-build-a-strawman from seansmithdesign's memory dir to the global always-loaded surface (~/.claude/CLAUDE.md). Leave feedback-overnight-autonomy and feedback-evidence-based-done where they are; add [[wikilinks]] so the cluster stays connected.

Wording (draft) — a sharp boundary, not a blanket override: 

When a request needs a design or taste decision (copy, scores, sizing,
layout), do not park it as a question or a "Phase N / needs input" item.
Build a concrete first-pass strawman Sean can react to on screen, and
surface only the one or two genuine forks alongside it. Reserve
question-rounds for decisions that change what gets built, or for
irreversible / outward-facing actions. Gating an item on input is how
requested work silently becomes never-done.

Honest read: this is best-effort prose. Placement (global, always loaded) and the sharp wording are the leverage, but a single line will not always beat a deeply trained, separately reinforced "ask first" default. That is precisely why Lever 2 exists and does not depend on this firing.

Lever 2 — Detection (the real backstop) replaces git-grep

Move: a structural form-check on carried-forward items. At handoff, before finalizing the pickup prompt, scan each carried item. Any item that is gated on input (phrased as a question, "needs Sean," "Phase N," "TBD") rather than carrying a strawman is itself the drop signal. Either build the strawman now, or surface it loudly: "carried as a question — decide or kill." Stamp a carried Nx since [date] tag in the carry text so repeat-carries are visible. No separate file (files rot, per the dead FOLLOW-UPS.md); the tag lives in the pickup prompt and ORCHESTRATOR.md In-Flight.

Why this beats git-grep: it inspects a small, present artifact (the carry list), not the whole transcript. It needs no semantic enumeration of "what Sean asked for" — the same judgment that failed three sessions running. It keys on the form of the item, which is exactly what the failure looked like.

Where: primary in claude-skills/wrap-continue/SKILL.md (Step 3, the pickup prompt — the high-frequency skill actually in the failure chain). Secondary in claude-skills/wrap/SKILL.md (Step 5, In-Flight).

Hardening (fast-follow, optional): a tripwire hook mirroring ship-quality-gate.sh — on write to the pickup prompt / ORCHESTRATOR.md, grep for gating phrases and inject a reminder if found. Crude (false positives on legitimate questions), but it fires by default. Recommend the skill-step baseline now, the hook as a fast-follow once the phrasing rules are settled.
